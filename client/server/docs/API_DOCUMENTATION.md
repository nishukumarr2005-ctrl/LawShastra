# API Documentation

Base URL: `http://localhost:5000/api/v1`

## Auth

### POST /auth/register
Creates a user account.

### POST /auth/login
Logs a user in and returns a JWT.

## Categories

### GET /categories
Retrieve all categories.

### GET /categories/:id
Retrieve one category.

### POST /categories
Create a category.

### PUT /categories/:id
Update a category.

### DELETE /categories/:id
Delete a category.
